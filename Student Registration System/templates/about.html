About the Project

Project Overview

The Student Registration System is a Flask-based web application that allows users to register students, store their details in an SQLite database, and view all records dynamically.

Features

  • Student Registration Form
  • SQLite Database Connectivity
  • Dynamic Data Storage
  • Dynamic Student Records Display
  • Flask Routing and Template Rendering
  • Responsive User Interface

Team Information

Developed as part of the Summer Internship Program using Flask, HTML, CSS, and SQLite.
